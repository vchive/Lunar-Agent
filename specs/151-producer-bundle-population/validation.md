# Feature 151 validation

The focused suite uses local regular UTF-8 files and Feature 150 verified bundles. It covers a
successful two-file projection, stable entrypoint/source-file mapping, provenance-only metadata,
duplicate IDs, cross-bundle path reuse, tampering, invalid roots, and no-write behavior. Related
candidate bundle and producer suites remain the source-integrity regression.

The feature is provider-free. It does not establish producer effectiveness or framework parity.
