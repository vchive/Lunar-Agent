# Round Feedback Contract

The deep subject request may contain `previous_evaluation: null` for round one or a version-1
`RoundFeedback` object for later rounds. The object is generated by Lunar after exact harness
evaluation and is not accepted from the subject receipt.

Safe fields:

- finite nullable scores and score delta;
- best round and best score;
- closed failure category and directive enums;
- generic allowlisted numeric detail metrics;
- at most 64 candidate path/size/SHA-256 entries;
- bounded stagnation metadata.

Never include private evaluator paths, raw output, baseline rows, credentials, or candidate file
contents. Unknown detail metric names are dropped. A malformed object, absolute path, symlink
manifest entry, or invalid digest is rejected.
