# Data Model: Standalone Local Famou Agent

## Run

Represents one user goal.

| Field | Type | Rules |
|---|---|---|
| `id` | string | Stable unique identifier, generated by the controller |
| `goal` | string | Non-empty user request |
| `status` | enum | `pending`, `running`, `succeeded`, `failed`, `cancelled` |
| `workspace` | path | Must be inside the configured local data directory |
| `created_at` | timestamp | UTC |
| `updated_at` | timestamp | UTC |

## Task

Represents an executable unit in a run plan.

| Field | Type | Rules |
|---|---|---|
| `id` | string | Stable unique identifier |
| `run_id` | string | References `Run` |
| `parent_id` | string/null | Optional hierarchy reference |
| `title` | string | Human-readable label |
| `prompt` | string | Runtime input, persisted before execution |
| `state` | enum | `pending`, `ready`, `running`, `waiting`, `blocked`, `succeeded`, `failed`, `cancelled`, `uncertain` |
| `dependencies` | JSON array | Task IDs that must be verified before scheduling |
| `attempts` | integer | Non-negative count |
| `result_path` | path/null | Run-scoped result artifact |

## Attempt

Represents one invocation of a Runtime Adapter.

| Field | Type | Rules |
|---|---|---|
| `id` | string | Stable unique identifier |
| `task_id` | string | References `Task` |
| `runtime` | string | Adapter name, such as `mock` or `subprocess` |
| `session_id` | string/null | Opaque runtime handle |
| `status` | enum | `running`, `succeeded`, `failed`, `cancelled`, `uncertain` |
| `started_at` | timestamp | UTC |
| `finished_at` | timestamp/null | UTC |
| `heartbeat_at` | timestamp/null | UTC |
| `error` | string/null | Sanitized diagnostic |

## Event

Immutable operational history item. `id` is the idempotency key; inserting the same ID twice is a
no-op.

| Field | Type | Rules |
|---|---|---|
| `id` | string | Caller-provided unique event ID |
| `run_id` | string | References `Run` |
| `task_id` | string/null | Optional task reference |
| `type` | string | Names a state transition or operational fact |
| `payload` | JSON object | Must be serializable and must not contain secrets |
| `created_at` | timestamp | UTC |

## Artifact

Metadata for a file stored inside a run workspace. Paths are normalized and must not escape the run
root. The first implementation records SHA-256, byte size, and media kind.

## Approval

An authorization request for a policy-controlled action. P1 defines the entity and event vocabulary;
interactive approval UI is deferred until the controller loop is stable.

## State Invariants

1. A `succeeded` or `failed` task has no future attempt that can change its terminal result.
2. A run is `succeeded` only when all required tasks are verified successful.
3. Every task state change has an event, and every artifact is linked to its producing task.
4. Recovery may move `running` to `uncertain` and then to `ready`/`pending`, but never silently to
   `succeeded`.
