# Feature 085 offline quickstart

This scenario uses temporary workspaces, deterministic generators/evaluators, a Feature 084 seed
fixture, and a fake OpenEvolve-compatible executable. It does not run a model, provider, real
OpenEvolve process, remote backend, company evaluator, or campaign.

## Prerequisite admission

First run the Feature 084 offline fixture. Confirm one valid and one invalid manifest record are
fully adjudicated, only the admitted subset is committed, and its local receipt and handoff
fingerprint survive resume. Do not continue Feature 085 verification if that gate fails.

## New active defaults

Start a standalone evolution run from the admitted seed without `--strategy`:

```bash
lunar-agent evolve contract.json \
  --seed-manifest /absolute/path/to/seed-manifest.json \
  --seed-dependency-sha256 aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa \
  --seed-environment-sha256 bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb \
  --generator-command "/absolute/path/to/fake-generator" \
  --evaluator-command "/absolute/path/to/fake-exact-evaluator" \
  --max-rounds 2 --json --home /absolute/path/to/new-home
```

Confirm the request, state, candidates, and result use `strategy=population`; the verified seed is
generation 0 and iteration 0, and the first formal iteration follows admission. Repeat through
conversational `solve --evolve` and confirm its linked evolution run also defaults to population.
This command deliberately selects Feature 084's optional generic-evolve import path. Its manifest
must contain matching dependency/environment digests, contract digest, and
`evaluator_kind=exact_harness` identity for the explicit local evaluator command. Either digest
flag without `--seed-manifest`, a manifest without both flags or without the exact evaluator, a
manifest used with OpenEvolve, or more admitted seeds than `population_size` must fail before
active-state mutation. The seed flags are not added to staged or benchmark commands.

Run `benchmark` without `--strategy` and confirm it creates exactly one population workspace:

```bash
lunar-agent benchmark contract.json \
  --generator-command "/absolute/path/to/fake-generator" \
  --evaluator-command "/absolute/path/to/fake-exact-evaluator" \
  --max-rounds 2 --seed 7 --json --home /absolute/path/to/new-home
```

## Retired strategy and runtime loop

Request `--strategy loop` with a fresh destination. Confirm the command returns
`loop_strategy_retired` before creating a run/workspace or calling the fake generator/evaluator.
Import `LoopStrategy` from both the public package and evolution module; invoking its `run()` or
`resume()` must produce the same non-mutating retirement outcome. Separately deserialize a legacy
loop fixture and confirm its original tag and result remain readable.

Run the existing deterministic Agent-loop tests. `AgentLoopRuntime`, ordinary `--agent-loop`, and
`--agent-runtime-loop` must still execute their bounded model/tool runtime fixtures; none may create
an evolution state whose strategy is loop.

## Explicit OpenEvolve boundary

The fake wrapper may emit candidate source and an attractive external score. Supply the local exact
evaluator explicitly:

```bash
lunar-agent evolve contract.json \
  --strategy openevolve \
  --openevolve-command "/absolute/path/to/fake-openevolve-wrapper" \
  --evaluator-command "/absolute/path/to/fake-exact-evaluator" \
  --json --home /absolute/path/to/new-home
```

Confirm the external score remains provenance-only and the candidate is ranked only from the local
receipt. Confirm the fake producer sees a private mode-0700 temporary workspace, and that canonical
records contain only digest summaries rather than the raw external evaluation, metadata, stdout, or
stderr. Resume the completed run: the producer invocation count must remain one, the local evaluator
count must become two, and the stable `seed-*` candidate/receipt must still verify. Repeat without
`--evaluator-command`; it must fail before executing the wrapper or writing a ranked candidate.
